    Your business account

    Your own balance, transaction history, merchant onboarding and cash dispensing.

    The business account is your own. Read the balance before a payout run, reconcile against the transaction history, and onboard the merchants you aggregate.

    On this page

    • Check the business account balance
    • Get the transaction history
    • Get the recent transactions
    • Check an operation's status
    • Onboard a merchant
    • Dispense cash

    Operations

    Check the business account balance

    #
    Business API POST/accountBalance principal / credentials headers referenceNumber

    Returns the business account balance.

    • Check availableBalance, not totalBalance, before a payout run — it is what you can actually send.

    Rust

    get_business_balance

    let balance = client.get_business_balance("BAL-2026-0042").await?;
println!("{:?}", balance.available_balance);

    Get the transaction history

    #
    Business API POST/transactionHistory principal / credentials headers referenceNumber

    Returns every transaction on the business account between two dates: money in, money out and fees, up to 10,000 at a time.

    • Use it to reconcile your records with Paga's.

    Rust

    get_business_transactions

    let history = client
    .get_business_transactions(GetBusinessTransactions::new(
        "HIS-2026-0042",
        "2026-11-01T00:00:00",
        "2026-11-04T00:00:00",
    ))
    .await?;

    Get the recent transactions

    #
    Business API POST/recentTransactionHistory principal / credentials headers referenceNumber

    Returns the last five transactions on the business account, newest first, without a date range.

    • For anything further back, use the transaction history endpoint.

    Rust

    get_recent_transactions

    let recent = client
    .get_recent_transactions(GetRecentTransactions::new("REF-000001"))
    .await?;

    Check an operation's status

    #
    Business API POST/getOperationStatus principal / credentials headers referenceNumber

    Returns the status of a business operation.

    • The status is in transactionStatus, not status.

    Rust

    get_operation_status

    let status = client
    .get_operation_status(GetTransactionStatus::new("PAY-2026-0311"))
    .await?;
println!("{:?}", status.transaction_status);

    Onboard a merchant

    #
    Business API POST/onboardMerchant principal / credentials headers referenceNumber + merchantExternalId + name + phone + email

    Onboards a merchant and returns the credentials Paga issues for it.

    • For aggregators only.
    • Paga names the request field reference, not referenceNumber.

    Rust

    onboard_merchant

    let merchant = client
    .onboard_merchant(OnboardMerchant::new(
        "REF-000001",
        "MERCH-1",
        serde_json::json!({ "name": "Acme Ltd" }),
        serde_json::json!({
            "firstName": "Bello",
            "lastName": "Ramon",
            "phone": "08064343187",
            "email": "director@example.com",
            "dateOfBirth": "1989-10-02",
        }),
        serde_json::json!({
            "type": "EMAIL_NOTIFICATION",
            "financeAdminEmail": "finance@example.com",
        }),
    ))
    .await?;

    Dispense cash

    #
    Business API POST/dispenseCash principal / credentials headers referenceNumber + customerPhoneNumber + amount + withdrawalCode

    Dispenses cash against a customer's withdrawal code.

    Rust

    dispense_cash

    let cash = client
    .dispense_cash(DispenseCash::new(
        "CASH-2026-0042",
        "08064343187",
        5000.0,
        "123456",
    ))
    .await?;
