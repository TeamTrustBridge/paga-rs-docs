    Dynamic virtual account, Bank USSD, Paga wallet and USD bank transfer

    Collect money from a customer with a payment request. The same request serves the virtual account, USSD, wallet and USD flows — you pick the method.

    A payment request tells Paga to collect a specific amount from a specific customer. How the customer pays is up to you: a one-time virtual account number, a USSD prompt, their Paga wallet, or a USD bank transfer.

    Operations

    Create a payment request

    #
    Collect API POST/paymentRequest HTTP Basic referenceNumber + amount + currency + payer.phoneNumber + payer.email

    Creates a payment request. The customer pays via the payment methods you send, and Paga calls your callback when the payment completes.

    • The same operation serves the Bank USSD, Paga wallet and USD bank transfer flows — pick the flow with paymentMethods.
    • payer.email takes part in the hash even when you omit it.

    Rust

    create_payment

    let payment = client
    .create_payment(CreatePayment::new(
        "ORD-2026-0187",
        50.0,
        "Bello Ramon",
        "08064343187",
        "Your business name",
    ))
    .await?;

    Check payment status

    #
    Collect API POST/status HTTP Basic referenceNumber

    Returns the status of a payment request. The outer statusCode only says whether the status request worked; the payment's own status is in data.statusCode.

    • data.statusCode of "0" means the payment was paid.

    Rust

    get_payment_status

    let status = client.get_payment_status("ORD-2026-0187").await?;
if status.data.as_ref().and_then(|d| d.status_code.as_deref()) == Some("0") {
    println!("paid");
}

    List the customer's banks

    #
    Collect API POST/banks HTTP Basic referenceNumber

    Lists the banks available for a Bank USSD payment. Send a bank's uuid as payer.bankId when creating a payment request, or as autoSweep.bankPublicId for subsidiary accounts.

    Rust

    get_collect_banks

    let banks = client.get_collect_banks("REF-000001").await?;
for bank in banks.banks.unwrap_or_default() {
    println!("{:?} {:?}", bank.name, bank.uuid);
}

    Check USD payment status

    #
    Collect API POST/status HTTP Basic referenceNumber + paymentCurrency

    Returns the status of a USD payment request. Unlike the other /status operations, this one signs the currency as well as the reference number.

    • data.statusCode of "1" means the payment is still pending.

    Rust

    get_usd_payment_status

    let status = client
    .get_usd_payment_status("ORD-2026-0187", "USD")
    .await?;

    Payment request history

    #
    Collect API POST/history HTTP Basic referenceNumber

    Returns the history of your payment requests.

    Rust

    get_payment_request_history

    let history = client.get_payment_request_history("REF-000001").await?;
