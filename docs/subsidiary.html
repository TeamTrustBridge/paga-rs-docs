    Subsidiary accounts

    Paga accounts for your customers, held on your behalf. Issue, hold and move money on their account.

    A subsidiary account is a Paga account for one of your customers. You can hold their money, move it between accounts, and set it up to sweep straight into a bank account.

    Operations

    Create a subsidiary account

    #
    Collect API POST/subsidiary-accounts HTTP Basic referenceNumber + accountReference + iifiNumber + autoSweep.bankPublicId + autoSweep.destination + autoSweep.accountNumber + callbackUrl

    Creates a Paga account for one of your customers.

    • Leave out autoSweep for a ledger-backed account that holds funds; set autoSweep.destination to VIRTUAL_ACCOUNT or BANK for a virtual account that settles straight away.
    • Reusing a referenceNumber or accountReference returns status code 102 and never creates a second account.

    Rust

    create_subsidiary_account

    let account = client
    .create_subsidiary_account(CreateSubsidiaryAccount::new(
        "REF-000005",
        "CUST-000184-WALLET",
        "Bello Ramon",
    ))
    .await?;

    Charge a subsidiary account

    #
    Collect API POST/subsidiary-accounts/{accountReference}/charge HTTP Basic referenceNumber + amount + currency + narration

    Debits a ledger-backed subsidiary account.

    • Not available on virtual accounts.
    • Retrying with the same referenceNumber never moves money twice.

    Rust

    charge_subsidiary_account

    let charge = client
    .charge_subsidiary_account(ChargeSubsidiaryAccount::new(
        "CUST-000184-WALLET",
        "REF-CHARGE-001",
        1000.0,
    ))
    .await?;

    Top up a subsidiary account

    #
    Collect API POST/subsidiary-accounts/{accountReference}/topup HTTP Basic referenceNumber + amount + currency + narration

    Credits a ledger-backed subsidiary account from your business balance.

    • Not available on virtual accounts.

    Rust

    top_up_subsidiary_account

    let top_up = client
    .top_up_subsidiary_account(TopUpSubsidiaryAccount::new(
        "CUST-000184-WALLET",
        "REF-TOPUP-001",
        500.0,
    ))
    .await?;

    Transfer between subsidiary accounts

    #
    Collect API POST/subsidiary-accounts/transfer HTTP Basic referenceNumber + sourceAccountIdentifier + destinationAccountIdentifier + amount + currency + narration

    Moves money between two ledger-backed subsidiary accounts.

    • Paga sends one callback, for the source account only.

    Rust

    transfer_between_subsidiary_accounts

    let transfer = client
    .transfer_between_subsidiary_accounts(
        TransferBetweenSubsidiaryAccounts::new(
            "CUST-000184-WALLET",
            "CUST-000221-WALLET",
            "REF-TRANSFER-001",
            1500.0,
        ),
    )
    .await?;

    Retrieve a subsidiary account

    #
    Collect API GET/subsidiary-accounts/{accountReference} HTTP Basic referenceNumber + accountIdentifier

    Returns an account's details, limits, callback URL and balance.

    • The accountIdentifier is the account's accountReference.

    Rust

    retrieve_subsidiary_account

    let account = client
    .retrieve_subsidiary_account("CUST-000184-WALLET", "REF-GET-001")
    .await?;

    Update a subsidiary account

    #
    Collect API PUT/subsidiary-accounts/{accountReference} HTTP Basic referenceNumber + accountIdentifier + iifiNumber + autoSweep.destination + autoSweep.bankPublicId + autoSweep.accountNumber + callbackUrl

    Changes an account.

    • Send only what you want to change.
    • accountNumber and accountReference cannot be changed.

    Rust

    update_subsidiary_account

    let account = client
    .update_subsidiary_account(UpdateSubsidiaryAccount::new(
        "CUST-000184-WALLET",
        "REF-UPDATE-001",
    ))
    .await?;

    Get a subsidiary account balance

    #
    Collect API GET/subsidiary-accounts/{accountReference}/balance HTTP Basic referenceNumber + accountIdentifier

    Returns an account's balance.

    Rust

    get_subsidiary_balance

    let balance = client
    .get_subsidiary_balance("CUST-000184-WALLET", "REF-BAL-001")
    .await?;
println!("{:?}", balance.balance);

    Get a subsidiary account history

    #
    Collect API GET/subsidiary-accounts/{accountReference}/history HTTP Basic accountIdentifier + startDateTimeUTC + endDateTimeUTC

    Returns an account's transactions.

    • Up to three months at a time.
    • Pages start at 0.
    • referenceNumber is required as a query parameter, but is not part of the hash.

    Rust

    get_subsidiary_history

    let history = client
    .get_subsidiary_history(GetSubsidiaryHistory::new(
        "CUST-000184-WALLET",
        "REF-HIS-001",
        "2026-06-01T00:00:00",
        "2026-06-30T23:59:59",
    ))
    .await?;
