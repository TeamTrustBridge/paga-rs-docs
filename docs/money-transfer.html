    Money Transfer

    Send money out of your business balance to a bank account or a Paga wallet.

    A money transfer moves money from your business balance to somebody else. You can validate the destination first, send in bulk, and check the status afterwards.

    On this page

    • List institutions you can pay
    • Validate the destination account
    • Send money to a bank account
    • Send money to a Paga wallet
    • Validate a Paga wallet transfer
    • Bulk money transfer

    Operations

    List institutions you can pay

    #
    Business API POST/getBanks principal / credentials headers referenceNumber

    Lists every institution money can be sent to, with the uuid you send as destinationBankUUID.

    • UUIDs never change, but new institutions are added every month — cache the list and refresh it weekly or monthly.
    • To send to a Paga wallet, use Paga's UUID AAAAAAAA-AAAA-AAAA-AAAA-AAAAAAAAAAAA.

    Rust

    get_banks

    let banks = client.get_banks("REF-000001").await?;
for bank in banks.banks.unwrap_or_default() {
    println!("{:?} {:?}", bank.name, bank.uuid);
}

    Validate the destination account

    #
    Business API POST/validateDepositToBank principal / credentials headers referenceNumber + amount + destinationBankUUID + destinationBankAccountNumber

    Confirms the account exists and returns the account holder's name and the fee, before any money moves.

    • Send amount exactly as you will send it later: "5000.00" and "5000" sign differently.

    Rust

    validate_deposit_to_bank

    let validation = client
    .validate_deposit_to_bank(ValidateDepositToBank::new(
        "REF-000002",
        "5000.00",
        "40090E2F-7446-4217-9345-7BBAB7043C4C",
        "0000000000",
    ))
    .await?;

    Send money to a bank account

    #
    Business API POST/depositToBank principal / credentials headers referenceNumber + amount + destinationBankUUID + destinationBankAccountNumber

    Sends money from the business balance to a bank account, or to a Paga wallet using Paga's UUID.

    • Send amount as a string (e.g. "5000.00") — it is signed verbatim.
    • There is no callback for the outcome; use the transaction status endpoint.

    Rust

    send_money

    let transfer = client
    .send_money(SendMoney::new(
        "PAY-2026-0311",
        "5000.00",
        "40090E2F-7446-4217-9345-7BBAB7043C4C",
        "0000000000",
    ))
    .await?;

    Send money to a Paga wallet

    #
    Business API POST/moneyTransfer principal / credentials headers referenceNumber + amount + destinationAccount

    Sends money from the business balance to a Paga user, identified by their phone number, nickname or account number.

    • referenceNumber must be at most 50 characters.

    Rust

    transfer_to_paga_wallet

    let transfer = client
    .transfer_to_paga_wallet(TransferToPagaWallet::new(
        "PAY-2026-0312",
        5000.0,
        "08064343187",
    ))
    .await?;

    Validate a Paga wallet transfer

    #
    Business API POST/validateMoneyTransfer principal / credentials headers referenceNumber + amount + destinationAccount

    Confirms the recipient exists and returns their name, registration status, KYC level and the fee, before any money moves.

    Rust

    validate_money_transfer

    let validation = client
    .validate_money_transfer(ValidateMoneyTransfer::new(
        "REF-000003",
        5000.0,
        "08064343187",
    ))
    .await?;

    Bulk money transfer

    #
    Business API POST/moneyTransferBulk principal / credentials headers referenceNumber + amount + destinationAccount + itemCount

    Sends up to 300 money transfers in one call.

    • Paga hashes the **first item's** reference number, amount and destination account, followed by the total number of items — the SDK does that for you.
    • A bulk transfer can partially succeed, so check every entry in results.

    Rust

    send_bulk_money_transfer

    let bulk = client
    .send_bulk_money_transfer(SendBulkMoneyTransfer::new(vec![
        BulkTransferItem::new("ITEM-1", 100.0, "08064343187"),
        BulkTransferItem::new("ITEM-2", 200.0, "08064343188"),
    ]))
    .await?;
